# Nuts-Classification-using-YOLO-model

- Developed a **custom-trained YOLO model** capable of detecting and classifying multiple screw nut types ('Castle Nut', 'Coupling Nut', 'Flange Nut', 'Square Nut', 'Well Nut', 'Wing Nut') from images.
- Built a **full-stack web application** that enables users to search for nut suppliers by **location** and **price**.
- Integrated an **image upload/capture module** that uses the YOLO model to automatically identify the nut type from user-provided photos.
- Implemented a **dynamic backend pipeline** that retrieves and filters supplier data from an **Excel-based database** based on the detected nut category.
- Delivered a system that provides **real-time supplier recommendations**, ensuring faster and more accurate nut identification and sourcing.
